# 重型坦克 Boss 实现方案

## 需求与选择

三阶段独立生命：120 → 120 → 30。坦克车体仅沿四个轴向移动，炮塔可以全向瞄准；休息只停止移动，射击和换弹继续。第一阶段移动 3 秒、休息 5 秒；第二阶段移动 3 秒、休息 3 秒。主炮弹匣 1 发、换弹 3 秒；过载炮弹同时爆炸并留下燃烧。过载机枪独立弹匣 5 发、换弹 5 秒、间隔 0.3 秒。驾驶员全向移动，保持至少 20 单位距离，手枪弹匣 3 发、间隔 0.5 秒、换弹 3 秒，每轮射击结束后随机选位，抵达后准备下一轮。

未指定的初始平衡：车速 32/46，驾驶员速度 60，主炮伤害 8、爆炸半径 42，燃烧每 0.5 秒 1 点、持续 4 秒；机枪伤害 2、手枪伤害 3。全部放在 Boss 场景 Inspector 导出字段中。驾驶员选位采用射线与碰撞检测避开墙体、水和掩体，贴身时优先后退；选位失败会继续尝试而不穿墙传送。

## 代码接入

- 提取 `BattlefieldBoss` 作为最小公共生命周期接口，General 保留现有行为。
- 房间追踪、HUD、Boss 奖励和出口统一监听最终死亡；中间阶段不会算作击杀。
- Boss 场景池包含 General 和重型坦克，默认等概率。使用独立 RNG 和房间 population_seed，保证关卡种子可复现且不干扰房间布局 RNG。每间房只生成一次。
- 独立 `TankShell` 复用现有弹丸、爆炸与燃烧；在碰撞查询结束后创建范围效果，避免物理回调中直接修改空间。
- 炮塔后坐、履带滚动、过载热光、阶段转换与驾驶员跑动由新增视觉控制器驱动。坦克碰撞范围大于驾驶员，第三阶段收缩碰撞体。
- 增加坦克炮、机枪、履带、装填、过载与出舱音效，走现有 SFX 总线。

## 验证范围

检查三级生命切换、最终死亡只触发一次、四轴运动与节奏、各武器弹匣/换弹/射速、驾驶员随机选位和最小距离、炮弹范围效果与阵营过滤、可复现随机 Boss 池、房间清场/出口/HUD，以及既有升级和 General 行为回归。图形、听觉和长期平衡另按实际可运行环境记录证据。

## 使用与配置

- Boss 预制体：`Prefab/BossTank/boss_tank.tscn`。阶段生命、速度、移动/休息时长、弹匣、射速、装填、炮弹与燃烧参数均可在根节点 Inspector 调整。
- 正式随机池：`FortressLevelController.boss_scenes`，默认两个 Boss 等概率；可以在关卡场景 Inspector 增删。独立运行旧 `TestLevel` 场景仍是其手动配置的 General，正式随机 Boss 逻辑由房间控制器负责。
- 独立试战：在 Godot 打开 `Scene/BossTankArena/BossTankArena.tscn` 按 F6。带玩家、三把武器、掩体、血条与重新挑战按钮，不结算研究点数。
- Godot 实际渲染的三阶段预览：`docs/art/tank_runtime_preview.png`，展示时放大三倍便于检查细节。
- 美术切片与合成音效的重新生成入口见 `Assets/Art/MilitaryArcade/Tank/README.md`。

坦克阶段移动时长按时间推进，即使被阻挡仍会按节奏进入休息。驾驶员选择直线可达的随机点，移动时继续避障；靠近玩家的主动位移不会跨越 20 单位间距，玩家主动贴近时驾驶员尝试退开，墙体可能限制退路。换位与换弹并行，抵达后才开启下一轮。

- `tests/battlefield_upgrade_test.tscn`：241 项通过。
- 既有闯关流程以临时 Node 场景入口运行：224 项通过（原 `--script` 入口有 AutoLoad 编译时序问题，未改动原测试）。
- 独立试战场已运行 120 帧，未发现新增脚本/场景运行错误。
- 已通过 macOS Godot 4.7.2 OpenGL/Apple M2 Pro 的图形运行并检查三阶段预览。音效资源已接入，长期战斗平衡与完整人工听感调音尚待游玩验证。
