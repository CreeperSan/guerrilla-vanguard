# Boss 扩展实施与验证

## 已实现

五名新 Boss 共用 `Prefab/BossSquad/tactical_boss.gd` 的两阶段生命周期，五个预制体保存各自生命、策略、名称与移动参数。四角护卫通过 `boss_guard.gd` 真实碰撞移动；地雷与手雷通过 `boss_hazard.gd` 管理启动、预警、射毁和爆炸。

七个主题的 `theme.tres` 明确设置 `boss_scene` 与 `boss_room_scene`。关卡控制器不再随机抽取 Boss；地图生成器（含兜底）为 Boss 预留 2×2 占地。七个 `Scene/BossRooms/*.tscn` 独立保存固定掩体与 BossSpawn，普通房间仍使用原有随机逻辑。后续可直接在这些场景中编辑固定布局。

Boss 最终死亡只触发一次结算；当前 Boss 房的其他敌人通过生命组件执行死亡，停止补员并清理敌弹、地雷、爆炸和燃烧。连带清场与补员单位不产生重复积分/掉落，其他房间和佣兵不受影响。

方向盾与燃料罐弱点使用统一生命接口新增的可选世界来源位置。现有调用可省略，保持原有行为；弹丸、爆炸和燃烧提供真实来源位置。盾牌第一阶段正面承受 25% 伤害、第二阶段 50%，装填和恢复时放盾；焚城背部额外承受 50% 伤害。

## 试战入口

在 Godot 打开 `Scene/BossRooms/BossPractice.tscn` 按 F6。左上选择主题，可以体验全部七个 Boss，配有阶段血条、重试按钮和初始冲锋枪/霰弹枪。试战不接入正式积分、钱包或关卡推进。正式主题场景仍可独立 F6 或从主菜单进入。

运行截图：`practice_preview.png`。角色图集、透明背景、固定掩体、四角护卫与试战 UI 已通过 macOS Godot 4.7.2 / Apple M2 Pro / OpenGL 实际渲染检查。
