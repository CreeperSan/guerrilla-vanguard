# 八主题远征设计与实现规格

本扩展保留既有关卡数、成长、武器、奖励与随机地图逻辑。正式主题池从 7 项扩至 15 项；空降仍随机取 5 个主题，总攻仍取 6 个随机主题并以地下要塞结束。八个新主题固定绑定各自 Boss。

## 视觉与声音制作规格

延续现有非像素军事街机绘制方式：俯视偏高视点、清楚深色轮廓、低对比地面、磨损材质。角色方向固定为下、右、上、左，人物不随枪口整体旋转。普通房间复用九种尺寸与两个样式，每个主题共 18 个模板；Boss 房单独手工布置，固定 2×2，占地 1000×1000 世界单位。

每主题源图为 4×4 等分图集：第一行是地面、墙、水、箱；第二行是掩体、装饰、入口、备用物件；第三行是 Boss 四方向；第四行是同伴或驾驶员四方向。地形纹理不带透视；独立物件保留透明度，不能把棋盘格绘制进图。打包只裁切和缩放，不覆盖旧图。

当前音频为原创程序合成：每主题一首八小节循环配乐，以及 intro / warning / attack / recover / phase 五个事件音效，共 8 首配乐、40 个短音效。22.05 kHz 单声道 PCM，固定种子、限幅和边缘淡化。配乐由 GameSettings 在进入新 Level 时交叉淡化并设置循环。它们用于当前可玩版本；真实无线电录音、街道／树林／水流环境录音和最终拟音仍需后续制作，不能将合成音等同于实录听感验收。

## 通用行为约束

- 首次激活等待 0.5 秒，再经历恢复与接近状态后开始攻击，入场不立即命中玩家。
- 一轮为接近 1 秒 → 锁定方向／落点预警 → 执行 → 恢复。预警默认 0.8 秒，狙击 1.2 秒，冲撞／重锤／水闸 1 秒。
- 同时只有一个主体动作；伙伴近战尽量在主体恢复时启动，机械犬单独围猎。
- 主体三管独立生命：普通主题 120 / 100 / 80；公路、沼泽、医院 160 / 130 / 100。阶段转换恢复 1.8 秒并取消旧危险区，不自动回复玩家血量。
- 目标为最近的存活玩家或已签约佣兵。伤害全部经 HealthComponent；玩家、佣兵的武器都能完成战斗，不设置必须持有的特殊武器。
- Boss 身体不阻挡玩家；自身移动受墙体约束。气垫艇忽略水体碰撞，仍受实体墙约束。
- 冲撞锁向后不追踪，每个目标每轮最多伤害一次，伤害 7；碰墙或冲刺结束恢复 2.6 秒。
- 预警圈显示实际伤害半径。持续危险区进入时伤害，停留每 0.75 秒结算一次，离开重入重新判定。最多同时六个，不在墙内或超出房间处生成。
- 可射毁陷阱／鱼叉锚点 6 生命，不发收益，不产生射毁爆炸。绳索拖拽通过物理移动，遇墙停止。
- 阶段生命耗尽不发最终死亡。仅最终死亡清理当前房间敌人和危险效果、结算既有 Boss 奖励并打开出口，复用原有去重逻辑。

## 八场遭遇

### 老城居民区：楼城督军

天井竞技场四角放置花槽，中部留环绕路线。第一阶段正面盾减伤至 30%，装填恢复与背面正常受伤。动作顺序：霰弹 → 霰弹 → 冲撞。霰弹五发，单发伤害 3，速度 240，射程 380。

第二阶段失去盾牌减伤，生成两名不补员的窗口枪手，各 18 生命，约 2.2 秒射击一次且要求视线畅通。主体使用三发扇射 → 燃烧落点 → 霰弹。燃烧区半径 44，二次落点预警 0.5 秒，持续 3 秒，每次伤害 4。

第三阶段使用霰弹 → 扇射 → 冲撞，提高接近速度。窗口援军不是独立通关目标；首领最终死亡时清场。

### 霓虹娱乐街：夜幕双煞

主体与黑衣搭档独立受击，搭档 70 生命。主体为遭遇血条；搭档有局部小血条。第一阶段交替三发扇射与交叉压制，搭档接近到约 110 距离后锁向 0.9 秒并突进，命中伤害 4。

第二阶段动作：交叉压制 → 扇射 → 电流落点。交叉压制用真实扇射与延迟落点夹击，落点半径 28；第三阶段由幸存者使用扇射 → 冲撞 → 霰弹。

搭档先死时白衣主体立即进入第三管；主体第二管先耗尽时由黑衣搭档继承主体节点和最终血条。不会出现两位各自发最终奖励。灯牌熄灭、整街明暗变化和双人同步演出属于后续表现增强，本版没有将全屏黑暗作为攻击机制。

### 郊野公园：灰熊

追踪兵与 45 生命机械犬组成围猎。第一阶段狙击 → 扇射，狙击锁向预警 1.2 秒，真实弹丸速度 600、射程 850、伤害 10。

第二阶段狙击 → 陷阱 → 狙击。陷阱落在锁定目标侧面 70 单位处，预警 1 秒、半径 25、存留 9 秒，可射毁。机械犬锁向突进，撞击伤害 4，随后恢复 2.8 秒。

机械犬被击毁后立即转第三管，追踪兵切换为霰弹 → 冲撞。主体先消耗两管也进入最终近战形态并移除犬；不保留不可见的追踪伤害。

### 化工厂：压力主管

第一阶段酸液落点 → 喷流。喷流持续 1.8 秒，最多每 0.4 秒发射一次真实弹丸，并在前方留下半径 27、持续 1.3 秒的酸区；追踪转速上限 0.5 弧度／秒。

第二阶段喷流 → 两侧排气 → 酸液。排气在主体两侧 125 单位，半径 55，预警 1 秒，持续 2 秒。背部来源伤害乘 1.5。

第三阶段喷流 → 排气 → 喷流；喷射后恢复增至 2.8 秒，形成压力失稳后的输出窗口。压力罐破裂动画和实体可破坏管线仍属于美术／机关增强，不虚构为已完成。

### 66号公路：末路车王

场地保留宽阔冲撞通道，两处护栏避开中轴。第一阶段冲撞 → 机枪扇射，装甲伤害系数 0.65，车体冲刺速度 220。

第二阶段冲撞 → 机枪 → 燃烧残骸落点，背面发动机来源伤害乘 1.5。第三阶段驾驶员下车，替换人物图集，实际身体半径缩为 12、受击半径缩为 18；动作机枪 → 手雷 → 机枪。

当前为固定场地战斗，不实现滚动公路追逐。美术未就绪时临时资源不会呈现战车外形，详见资源状态清单。

### 沼泽湿地：沉舟

第一阶段掠袭冲撞 → 五发炮座扇射。第二阶段掠袭 → 鱼叉 → 扇射。鱼叉预警后创建半径 30 锚点，持续 3.5 秒、伤害 3，并沿绳索方向以每秒最多 35 单位拖拽，可射毁解除。

第三阶段风扇损毁、搁浅：移动速度实际归零，采用扇射 → 鱼叉 → 扇射。鱼叉不是无法逃脱的强制抓取，玩家离开锚点范围或打掉锚点即可摆脱。

### 运河小镇：闸门长

第一阶段重锤 → 铆钉扇射。锤击圆心在前方 65，半径 65，主体预警后再延迟 0.25 秒落下，伤害 7。

第二阶段重锤 → 水闸 → 扇射。水闸以两侧带电积水危险区表示，中心各偏移 240、半径 100，预警 1.4 秒、持续 4 秒、伤害 2；中央保留安全通道。第三阶段重锤 → 冲撞 → 重锤。背部液压装置来源伤害乘 1.5。

本版积水以危险区表现，不改变 TileMap、不动态生成不可通行水墙；真实水面升降动画为后续表现增强。

### 废弃医院：零号病人

第一阶段重臂砸击 → 冲撞 → 药物抑制。抑制窗口 2.8 秒，蓝色圈提示可进攻。第二阶段砸击 → 异常增生 → 冲撞，增生在目标两侧 90 处创建半径 38 的危险区，预警 1 秒、持续 3 秒、伤害 3。

第三阶段冲撞 → 砸击 → 短暂清醒，清醒时停留 3.4 秒供输出。没有恢复意识时突然反伤或无预警爆发。病历、配音、实验室剧情与肢体逐帧异变动画不属于当前代码实现，后续可围绕这三个行为状态制作。

## 资源与当前交付状态

`assets.json` 是逐主题素材状态；`art_provisional: true` 代表仍复用旧主题纹理和旧 Boss 图集，仅支持逻辑试战，绝不能作为新场景正式美术验收。

本轮 imagegen 请求遭遇网络错误。提示词保存在 `imagegen_prompts.json`，源图目录预留在 `source/`；没有使用 API 密钥或切换付费 CLI。生成成功后将图放到 `source/<主题ID>.png`，运行 `python3 tools/build_expedition_content.py` 即可重新打包并更新资源状态；脚本保留旧主题素材和既有资源引用。

入口：`Scene/BossRooms/BossPractice.tscn` 可选十五个主题；各 `Scene/Level<主题ID>/<主题ID>Level.tscn` 可独立 F6 运行完整 Level。正式入口仍是 `Scene/GameRun/GameRun.tscn`。

自动测试不等同于实际画面与声音验收。后续应在 Godot 中确认透明边缘、角色方向、掩体轮廓、枪声提示可辨性、连续玩耍难度和手柄操作。
