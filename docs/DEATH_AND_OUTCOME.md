# 遗体与终局演出

## 遗体

`Prefab/Corpse/Corpse.tscn` 是独立 Node2D + Sprite2D 场景，没有碰撞、生命、AI、导航和逐帧脚本。
角色死亡当帧先创建并定位遗体，显示第一帧，再隐藏并关闭原角色。
普通敌人、佣兵和最终阶段的 Boss 在帧末释放原实例；玩家保留隐藏的数据节点，供 HUD 与战报读取。
遗体通过三个有限 Tween 帧回调播放倒地，结束后停在第三帧。
遗体动作使用独立 Tween，遇到普通暂停也能完成；终局字幕期间场景保持运行。

遗体归属于最近的房间，继承房间淡入淡出；清理房间、切换 Level 或退出闯关时随父节点释放。
死亡立即移出战斗分组，既不挡子弹、阻碍行走，也不阻止房间清场、重新被瞄准或再次计分。
同一角色通过元数据弱引用去重，重复回调不会生成第二份遗体。
佣兵专属死亡覆盖士兵入口，只通知一次永久死亡；Boss 换阶段不生成遗体。

## 编辑参数与美术

- `Script/Presentation/death_visuals.tres`：共享资源，默认每房间 40 具、每关 200 具；超预算按生成顺序淡出旧遗体，淡出默认 0.2 秒。
- `Script/Presentation/death_visual_config.gd`：帧尺寸、帧数、FPS 和上述预算的导出字段；默认三帧、6 FPS，总动作约 0.5 秒。
- `Prefab/Corpse/Corpse.tscn`：可在 Inspector 指定配置、动作行、显示层级；死亡图默认在活角色和掉落物下面。
- `Assets/Art/MilitaryArcade/Death/death_actions.png`：三列五行、每帧 96 × 80，五行依次是玩家、敌军、指挥官、佣兵死亡、玩家胜利。
- 同目录 `PROMPT.md` 保留内置 image_gen 生成方式与实际提示词，原始生成图也已留存。

目前是临时共用图集：三帧、单朝向，无血腥效果。Boss、载具驾驶员及机械犬使用通用占位倒地造型，后续可继续为兵种拆分图集。
运行时匹配原角色可见贴图的世界变换与帧尺寸；所有遗体引用共享图集，不逐个截取显存图像。
数量上限控制的是静态遗体；淘汰时短暂淡出的节点最多额外存活 `eviction_fade` 秒。
手机帧率与显存占用仍需目标设备实测，本次不提供未经测量的性能比例。

## 胜负流程

正式闯关根据 GameManager 路线长度判断最后一关，空降五关、反击七关使用同一逻辑。
最后一关生成地图时就不创建 BossExit；Boss 房所有敌人清除后自动提交通关，不生成战术奖励箱。
提交放在死亡回调完成后，确保最后一击积分、Boss 击杀与首领房统计包含在冻结战报内。
中间关卡继续生成可拾取的战术奖励，并通过出口进入下一关。

胜利：禁用玩家输入和受击区域、场景继续运行 → 玩家三帧举拳 → `Victory` 字幕缩放淡入 → 完整停留 3 秒 → 原有 RunResult。
战败：禁用玩家输入和受击区域、场景继续运行 → 玩家三帧倒地 → `Defeated` 字幕缩放淡入 → 完整停留 3 秒 → 原有 RunResult。
终局不暂停 SceneTree，粒子、飘字、子弹和其他场景动画继续运行。原玩家身体及全部碰撞区域被关闭，独立姿态节点展示胜利/倒地；战报和作战计时已在演出前冻结。
HUD 共用一次性的终局序列，重复信号不会重复创建字幕或进入多份结算。
反击通关后的结算到制作人员名单入口继续沿用已有流程。

`Scene/UI/RunOutcome/RunOutcome.tscn` 可编辑字幕大小、位置、字体、遮罩与颜色；脚本导出 `hold_duration` 默认 3 秒，`reveal_duration` 默认 0.4 秒。
3 秒从字幕显现完成时开始计算，前面的倒地/胜利动作与字幕淡入时间不占用这 3 秒。
