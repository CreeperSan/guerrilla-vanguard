# 金钱与研究点数

## 规则

- 金钱只在本次闯关内累计，Level 之间保留；胜利、战败或新局时清零，不写入存档。
- 普通敌人独立判定两次：默认 65% 掉落 4～12 金钱、18% 掉落 1～3 研究点数。可能同时掉落，也可能均不掉落。
- 地面货币需要玩家触碰拾取才入账，未拾取的货币不会计入结算。
- Boss 只有第二阶段最终死亡才直接增加 10～20 研究点数，无需拾取，第一阶段结束不奖励。
- 本局研究点数在胜利或战败结算时全部带出并持久化；直接停止运行、关闭游戏或未结算重建场景不会带出本局收益。
- 新局只重置金钱与本局研究点数，已经保存的研究账户保留。
- 概率和数量区间均在关卡根节点的「货币掉落」属性组调整；Boss 数量为 0 时可关闭奖励。

## 预制体与接口

| 路径 / 接口 | 用途 |
| --- | --- |
| `Prefab/Currency/money.tscn` | 金钱拾取物，金币图标与轻微缓动缩放 |
| `Prefab/Currency/research_point.tscn` | 研究点数拾取物，蓝绿色晶体图标 |
| `PrefabManager.create_currency(kind, amount)` | 创建预制体；调用方设置父节点和位置 |
| AutoLoad `CurrencyManager` | 管理局内钱包与持久研究账户 |
| `CurrencyManager.credit(kind, amount)` | 拾取和 Boss 直接奖励入账 |
| `CurrencyManager.try_spend_money(cost)` | 预留局内购买扣款；商品发放待后续实现 |
| `CurrencyManager.try_spend_research(cost)` | 预留闯关外强化扣款；升级效果待后续实现 |
| `CurrencyManager.get_snapshot()` | 获取金钱、本局研究、已存研究和结算状态 |

独立货币继承 LootItem，共用玩家已有拾取区和框标识；同帧重复触碰不会重复入账。也可以通过普通 LootItem 的 CurrencyMoney / CurrencyResearch 类型配置货币。音效放在 `Assets/Audio/SFX/money_pickup.wav` 和 `research_pickup.wav`，由玩家拾取播放器播放，沿用现有音效音量调节。

普通敌人的掉落延迟到物理回调结束后生成，并挂在敌人所属房间下。房间可见性、切关清理、懒加载继续生效。关卡之间使用同一个钱包，新战斗宿主创建时才重置局内收益。

## 结算和存档

持久文件：`user://research_account.cfg`，只保存已结算的研究余额与版本号，不保存金钱和未结算研究。Godot 编辑器可用「项目 → 打开用户数据文件夹」查看。

结算先写临时文件，再替换正式存档；成功后才更新内存账户余额。重复进入结果页不会再次增加研究。存盘失败时显示「尚未保存」，收益暂留内存，重新开始按钮先重试保存，仍失败则停留在结果页。读取已有账户失败时禁止覆盖它。

胜利与战败页面显示带出研究、已存账户以及金钱不带出的说明。战斗 HUD 顶部资源区显示金钱、本局研究、已存研究。

## 手动检查方法

1. F5 开始新局，检查金钱和本局研究为 0，已存研究显示上次结算余额。
2. 为快速检查，将关卡根节点两种掉落概率设为 1、数量设为 `(5, 5)` 和 `(2, 2)`。击杀普通敌人后应出现两种货币，未触碰前余额不变，触碰后分别增加 5 和 2 并播放不同音效。
3. 将概率设为 0，普通敌人死亡不应掉落对应货币；测试后恢复默认值。
4. 击败 Boss 第一阶段不奖励研究，第二阶段最终死亡直接增加研究，无需移动拾取。
5. 通过安全出口进入下一 Level，金钱、本局研究和已存研究应保持。
6. 战败或通关结算后，金钱为 0，已存研究增加本局研究；重复显示结果或重试按钮不重复入账。
7. 重新开始后本局余额为 0；关闭游戏并重新运行，已存研究仍在。
8. 在未结算时直接停止游戏，重新运行后不应带出本局收益。

本轮未新增或运行自动测试；拾取、音量、结果页和持久化行为需要在 Godot 实机检查。
