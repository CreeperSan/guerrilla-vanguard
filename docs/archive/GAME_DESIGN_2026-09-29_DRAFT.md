# Guerrilla Vanguard 游戏设计草案

> 状态：策划中。本文是单一事实来源；标记为“已确认”的内容不会因实现方便而擅自改变，“建议”需要讨论后才能定稿。数值在玩法流程确定前不视为平衡结论。

## 1. 项目目标

为 Godot 入门项目确定一个范围可控、能复用现有原型并可以逐步完成的俯视角射击游戏。首要目标是完成一款从开始到结局可玩的小游戏，而不是追求独特创意、复杂系统或内容规模。

### 范围原则

- 先做单人、单机、2D 俯视角射击；不做联机、开放世界、剧情分支或复杂模拟。
- 优先复用现有玩家、子弹、敌人、生命值、拾取物和场景原型。
- 房间内容以手工制作的预制场景为单位；随机的是房间组合，不是房间内部地图。
- 首个完整可玩版本就包含随机房间尺寸与分支；通过清晰的连通规则、房间数量上限和随机种子验证控制风险。
- 每个新功能都必须服务于核心循环；没有进入已确认范围的内容不实现。
- 先完成最小闭环并试玩，再调整数值。避免同时添加新武器、新敌人、新关卡和新成长系统。

## 2. 已确认设计

| 项目 | 决定 |
| --- | --- |
| 游戏类型 | 单人 2D 俯视角 RogueLike 射击 |
| 玩家操作 | 角色移动时朝移动方向转向；按住 `J` 自动朝当前角色朝向连续射击，不单独瞄准 |
| 目标体验 | 逐步打入敌方要塞，收集重要数据，强化己方作战能力，最终突袭指挥部并击败首领瓦解冲突 |
| 项目优先级 | 可完成、稳定、少返工；不以创意独特或内容丰富为目标 |
| 挑战结构 | 一轮包含多个关卡；每关由随机组合的预制房间构成 |
| 挑战期间成长 | 挑战进行中不返回指挥部升级 |
| 挑战结束 | 死亡或通关所有普通关卡后结算，再回作战指挥部升级 |
| 死亡重开 | 任意挑战中死亡后，下一轮回到普通第 1 关；最终任务失败也要重打 3 个普通关卡 |
| 情报结算 | 死亡或通关时，本轮已收集的情报都全额结算 |
| 关卡构成 | 每关随机组合预制房间；房间数随关卡推进增加 |
| 关卡连接 | 允许分叉与环路；每关确保包含军火商（商店）、武器库和通往下一关的出口房间 |
| 房间尺寸 | 宽和高可分别为 1、2、3 格，共 9 种 1×1 至 3×3 网格规格 |
| 首个完整可玩版本 | 必须包含 1×1 至 3×3 房间规格和随机分支，不作为后续扩展项 |
| 普通关卡数量 | 3 关，之后进入独立最终首领关卡 |
| 每关房间数 | 第 1–3 关依次为 6、8、10 间，包含入口与必需功能房间 |
| 最终任务房间数 | 5 关依次为 6、7、8、9、10 间，共 40 间；第 5 关以首领房替代出口房 |
| 每关房间类型 | 固定 4 间功能房（入口、商店、武器库、出口）；其余均为战斗房，分别为 2、4、6 间 |
| 战斗房敌人数 | 每间普通战斗房生成 3–5 名敌人 |
| 普通挑战时长 | 成功完成全部 3 个普通关卡，目标约 10–15 分钟；首领关另计 |
| 房间重复规则 | 开发原型允许同关重复预制房间；发布版同一关内不重复，跨关可复用 |
| 房间战斗规则 | 普通战斗房间封锁连接门，清除敌人后开放；商店、武器库和已清理房间可自由通行 |
| 资源用途 | 战场物资用于本轮商店消费；重要数据/情报只在结算后用于永久强化 |
| 结算后的货币 | 战场物资每轮结束清零；情报保留并累计用于永久强化 |
| 装备持久性 | 每轮结束清空武器、弹药与道具；永久情报、强化和最终任务解锁保留 |
| 永久成长 | 指挥部用已结算情报购买固定强化；每项有等级上限，不做技能树或随机强化 |
| 永久强化项目 | 最大生命、基础武器伤害、每轮出击的初始战场物资 |
| 初始武器 | 手枪免费；情报可一次性解锁其他初始武器，解锁后每轮可选，不重复付费 |
| 最终任务解锁 | 首次通关第 3 个普通关卡后解锁；玩家可在据点继续准备后再挑战 |
| 商店 | 使用本轮战场物资出售武器、弹药、投掷物/道具与战场支援 |
| 武器库 | 免费提供武器、弹药和道具，不提供战场支援 |
| 普通敌人数量 | 3 种普通敌人，另有 1 个最终首领 |
| 普通敌人类型 | 普通步兵（远程射击）、突击兵（快速近战）、重装兵（高生命远程射击） |
| 敌种递进 | 第 1 关普通步兵；第 2 关加入突击兵；第 3 关加入重装兵，已出现敌种继续出现 |
| 玩家射击 | 按住 `J` 自动射击当前朝向；射速待定 |
| 武器种类 | 手枪（默认）、冲锋枪、霰弹枪、狙击步枪、重机枪（强力武器） |
| 携带武器 | 手枪固定 + 2 个可替换武器槽；满格拾取时替换当前选中的非手枪武器 |
| 敌人远程攻击 | 普通步兵和重装兵发射可躲避的直线子弹，瞄准发射时玩家的位置，不追踪或预判 |
| 弹药与换弹 | 每种武器分别记录弹匣与备弹；按 `R` 手动换弹；不同枪型不共用弹药 |
| 最终任务 | 独立 5 关路线，复用随机房间生成；房间数依次为 6、7、8、9、10 间，第 5 关末尾为首领房 |
| 首领战 | 2 个阶段，低于半血时射速提高并增加三发扇形攻击；不召唤小兵 |
| 首领战时长 | 首领战本身目标约 1–2 分钟；最终任务整体时长待定 |

## 3. 故事与世界设定（待确认）

玩家扮演一名空降至敌后的游击队士兵，从要塞外围执行渗透和突袭任务。每次行动获取的重要数据会被带回己方指挥部，用于永久改善作战能力并解锁出击武器。准备充分后，玩家空降敌方指挥部，完成 5 关更长、更难的多房间突袭并击败最终首领。

### 叙事边界建议

- 使用虚构势力与虚构地点，故事只服务于关卡目标和成长循环。
- 不加入复杂阵营历史、可选对话、分支结局或大量过场。
- 重要数据作为抽象的任务情报，不扩展成密码破解、数据库管理等独立玩法。
- “瓦解冲突”暂按首领战后的战争结束结果理解；首领姓名、称号及结局表现待确认。

## 4. 核心循环

当前已确认的普通挑战循环：

1. 从作战指挥部出发，开始一轮挑战。
2. 依次推进多个关卡；每关从预制房间中随机组合。
3. 挑战期间收集重要数据，并从战场获取本轮商店可用的物资；不能返回指挥部升级。
4. 死亡或通关全部普通关卡时结束本轮；本轮已收集的情报全额结算并返回指挥部。
5. 在指挥部使用结算情报购买有等级上限的固定永久强化并一次性解锁出击武器，重新从第一关开始挑战。
6. 首次通关第 3 个普通关卡后解锁独立最终任务；玩家可在据点用情报准备出击武器，之后挑战复用随机房间生成的 5 关路线，并在第 5 关末尾挑战首领。

普通战斗房间在敌人未清除前封锁连接门；敌人清除后开放并保持开放。商店、武器库等功能房间不封门。是否必须清理出口所在路径之外的房间由玩家自行选择，支线可选。

本轮物资与情报分开记录：物资、武器、弹药和道具仅对本轮有效，死亡或通关结算后清零；情报在死亡或通关后全额结算并累计，用于指挥部永久强化。战场物资由敌人死亡掉落，掉落规则与数值待定。商店可出售武器、弹药、手雷、燃烧瓶、盾牌，以及两种战场支援：导弹打击、空投强力武器。武器库免费提供武器、弹药和道具，但不提供战场支援。战争迷雾清除不进入首版范围；商店库存和价格待定。

每种枪分别管理弹匣和备弹，按 `R` 手动装填；弹药不跨枪型通用。

永久强化采用固定选项逐级购买，每项设等级上限，不含技能树、随机强化或互斥分支。已确认项目为最大生命、基础武器伤害、每轮出击的初始战场物资；手枪免费，其他初始武器可用情报一次性解锁，之后每轮均可选择，无需重复付费。首次通关第 3 个普通关卡即可解锁最终任务，不要求强化全部升满。

普通步兵和重装兵使用直线投射物，在发射时瞄准玩家当前位置；子弹不追踪或预判。敌人具体射速、伤害和弹速待定。

最终任务由 5 个关卡组成，复用普通关卡的随机房间生成规则，难度更高；房间数依次为 6、7、8、9、10 间，第 5 关末尾为固定首领房。每关包含入口、商店、武器库及出口（第 5 关由首领房取代出口），其余房间为战斗房；敌人数仍为每房 3–5 名，通过敌种组合与数值增难。任意挑战中死亡都会结束当前挑战，下一轮从普通第 1 关开始；最终任务的解锁和永久强化保留，但要重新完成 3 个普通关卡才能再次出击最终路线。首领战本身目标时长约 1–2 分钟；首领拥有两个阶段，第二阶段在生命值低于一半时开始，沿用重装兵直线子弹并加快射击，另增加一种三发扇形攻击；不召唤小兵。

**复杂度提示：**这比固定关卡明显更复杂，风险主要在随机放置不重叠、房间门口正确连接、保证必需房间可达，以及不同尺寸组合后的边界情况。已确认首个完整可玩版本包含全尺寸范围、随机分支和环路，不以移除这些特性来缩小版本范围。控制复杂度的手段改为：房间内部固定制作、房间数有上限、必需房间有明确规则，并用可复现随机种子验证布局；每个房间必须从入口可达。具体占地规格和连接规则仍需定稿。

## 5. 首版范围提案（未确认）

| 维度 | 建议的首版上限 |
| --- | --- |
| 可操作角色 | 1 名 |

| 战斗房间 | 进入后封锁连接门；清除敌人后开门且保持开放；功能房间不封门 |
| 资源 | 独立的本轮战场物资用于商店；情报只结算至永久成长 |
| 战场物资来源 | 敌人死亡时掉落；掉落规则和数量待定 |
| 结算 | 本轮战场物资清零；情报全额结算并保留 |
| 装备持久性 | 普通挑战结束时清空本轮武器、弹药和道具；情报可用于购买/解锁初始武器 |
| 出击配置 | 手枪免费；用情报一次性解锁其他初始武器，之后每轮可选，不重复付费 |
| 商店/武器库 | 商店出售武器、弹药、投掷物、道具和战场支援；武器库免费提供武器、弹药和道具，不提供支援 |
| 首版战场支援 | 仅导弹打击与空投强力武器；不做战争迷雾系统 |
| 普通敌人 | 普通步兵远程射击；突击兵快速近战；重装兵高生命、慢速远程射击；按关卡逐步引入 |
| 远程攻击 | 普通步兵和重装兵使用可躲避的直线子弹，不追踪玩家 |
| 最终任务敌人数 | 仍为每战斗房 3–5 名；以敌种比例和数值提升难度 |
| 首领 | 1 名，两阶段、两种直线/扇形攻击；不召唤小兵 |
| 武器 | 首版限定 5 种：手枪、冲锋枪、霰弹枪、狙击步枪、重机枪；手枪默认，重机枪为强力武器 |
| 携带位 | 手枪固定在默认位，另有 2 个可替换武器槽；满格时替换当前选中的非手枪武器 |
| 弹药 | 每种武器拥有独立弹匣和备弹；按 `R` 手动换弹 |
| 成长 | 固定强化项逐级购买并设上限：最大生命、基础武器伤害、初始战场物资；不做技能树、装备词条或复杂构筑 |
| 最终任务解锁 | 首次通关第 3 关即解锁，玩家可选择继续准备 |
| 最终任务死亡 | 挑战进度重置至普通第 1 关；情报、永久强化和最终任务解锁保留 |
| 随机性 | 随机组合预制房间与连通布局；不随机生成房间内部内容 |
| 内容排除 | 联机、NPC 队友、载具、制作系统、复杂潜行、任务分支、随机词缀、多个结局 |

“首版”具体关卡数、撤离方式、失败惩罚和强化项目需要先通过策划对话确认。上表不是实现清单。

## 7. 数值设计原则（待定稿）

成功完成全部 3 个普通关卡的节奏目标为约 10–15 分钟；最终任务的整体时长待定，首领战本身约 1–2 分钟。再按“玩家每次攻击伤害 → 敌人生命 → 敌人攻击频率/伤害 → 玩家生命 → 关卡敌人数”的顺序一次调整少量变量。

每种敌人至少需要定义：生命、移动速度、攻击方式、攻击伤害、攻击间隔、攻击距离、情报/补给掉落规则。每把武器至少需要定义：伤害、射速、有效射程、弹匣容量、换弹时间、备弹量。最终关卡还需定义首领生命、招式数量和每阶段转换条件。

具体数值表将在核心循环和战斗操作确认后补齐，并注明单位、目标体验与验证场景；原型数值不直接升级为正式数值。

## 8. 策划决策顺序

按顺序逐项讨论，每次只冻结一个核心决定；完成后更新“已确认设计”和决策记录。

1. 行动结构与情报循环：一轮挑战、结算、死亡重开、据点永久强化。
2. 关卡生成边界：房间规格、必需房间、连通规则、每关房间数和逐关增量。
3. 首版关卡与生成验证：关卡数量、通关目标、房间预制件和生成有效性验收。
4. 战斗内容：起始武器、有限武器选择、敌人类型与首领机制。
5. 数值表：角色、武器、敌人、奖励与关卡节奏。
6. 完成标准：最小可玩版本的验收条件与明确不做清单。
