# 参考图导向的整体美术规范

状态：**美术规范已确认并已替换主要资源家族**。五张概念板仍仅作方向参考；玩家/敌人/将军/坦克图集、七主题完整地形组、十二种武器/补给图标、常用投射物/爆炸/燃烧、HUD 面板和菜单背景/字标已制作并替换到工程。中文界面字体和个别关卡专属物件仍待处理。当前已确认的玩家图集仍是比例与角色质感的首要对照。

## 基准顺序

1. 用户提供的森林交火截图确定镜头、画面密度、颜色对比、HUD 布局和整体笔触。
2. 已确认的玩家 24 帧图集确定玩家头盔、浅色袖口、棕色背包、短身比例、枪械体量和八方向枪口朝向。
3. 本目录五张概念板扩展敌人、环境、UI、物品和特效。概念板只提供方向，单项细节仍以游戏规则和截图为准。
4. 旧风格稿、旧像素图集和旧 HUD 只作为工程现状记录；与以上基准冲突时不沿用。

## 统一画面语言

- **镜头**：固定俯视偏斜视角，能看见人物头盔顶、脸/背包和物件顶面。人物枪口、身体朝向、弹道方向严格一致。墙、箱子、树冠的顶面和接地面要能分清，不使用正侧视透视。
- **轮廓**：主体用近黑的深棕/深绿轮廓；外轮廓略粗、内部结构线更细，线宽带轻微手绘起伏。缩到实际游戏尺寸时，玩家、敌人、可拾取物和弹幕仍可凭轮廓辨认。边缘保持抗锯齿。
- **造型**：圆角、简洁、略带玩具化比例，但不做亮面塑料或真实军事写实。玩家参考图里的头盔较大、脸和袖口浅、身体短、枪械清晰；同类角色共用尺度，靠头盔、背包、肩甲、武器等大形体区分身份。
- **上色**：主色平涂，辅以两到三档明暗和少量块状手绘纹理。材质通过轮廓、色块和少数高光说明；避免均匀噪点、细碎迷彩、照片贴图和繁复金属反射。
- **空间层级**：中心战斗区保持开阔、较少纹理；边缘布置树冠、墙面、建筑和高掩体。玩家/敌人/弹幕比地面更清晰更亮。环境暗部不吞掉角色和 UI。
- **统一尺度**：采用角色与关卡相对比例，不凭原始图片像素决定画面尺寸。以游戏实际相机缩放下已确认玩家图集为标尺：普通敌兵接近玩家；重装兵更宽；首领更大但保持清楚轮廓；箱子、掩体和补给按截图同类物件比例绘制。

## 阵营与功能配色

颜色用于快速识别，不取代形状区分。以下是方向范围，制作时以截图和已确认玩家贴图取样微调：

| 用途 | 色彩范围 | 使用方式 |
| --- | --- | --- |
| 玩家 | 灰橄榄绿、暗绿、浅米白、棕色 | 头盔/衣服为低饱和绿，袖口/脸用浅米色，背包和靴子用棕色 |
| 普通敌人 | 蓝灰、深海军蓝、少量珊瑚红 | 红色只用在小面积布条、瞄准提示和受击反馈；敌人轮廓与玩家区分 |
| 森林地面 | 深青绿树冠、黄绿草地、棕色土路 | 可走区比边缘树丛亮；少量浅色草点，不制造弹幕般的亮散点 |
| 木材/掩体 | 暖棕、蜂蜜木色、深褐阴影 | 轮廓和顶面结构清楚，不铺高频木纹 |
| 友方射击 | 白芯、暖黄/橙金外沿 | 小而尖，轨迹明确，枪口焰短促 |
| 敌方射击/预警 | 亮粉红/珊瑚红芯、浅色外缘 | 敌弹优先圆形，预警线/扇区用透明色块；与友弹形状同时区分 |
| UI | 炭黑绿、暖灰白、橄榄绿、少量金黄 | 深底承载文字和图标，浅色表示可读信息/选中；金黄只强调关键资源和焦点 |
| 生命/危险 | 红色、珊瑚色 | 限定在生命损失、低生命、危险预警，不铺成大面积装饰 |

## 各系统设计规则

### 角色与敌人

- 玩家沿用已确认图集的造型，不再加围巾、臂章、徽章或不在参考图中的装备。
- 普通敌人采用蓝灰头盔与制服，少量红色点缀；形体和玩家同属一套圆润小比例语言。
- 突击兵靠前倾姿态、近战武器和更明显的动作区别；重装兵靠宽肩、厚护甲和慢速轮廓区别，不能只靠颜色。
- 首领沿用项目已有的将军和坦克玩法设定，重新绘制时缩减小零件，以远距离轮廓、红色弱点或武器形状识别阶段。
- 每个方向的枪管轴线必须指向对应八方向瞄准向量。新枪型也要在实际小尺寸下辨认，不能让枪口被手臂或外轮廓遮住。

### 地形、建筑与掩体

所有地面使用宽色块与稀疏手绘斑点，不使用重复像素砖铺满全屏。阻挡物应有明显顶面、侧面、投影和可碰撞外形；投影只做轻量贴地提示。

| 当前主题 | 画面处理 | 识别重点 |
| --- | --- | --- |
| Jungle 森林 | 黄绿色开阔草地，深绿叶冠沿边缘围合 | 可走草地与深色树丛/树干分层 |
| Village 村落 | 暖土、木屋、篱笆、补给棚 | 建筑轮廓靠房檐、门窗和木色区分 |
| Valley 山谷 | 明亮草地、低矮石块、稀疏树丛 | 中央开阔，坡地/岩石负责房间边缘变化 |
| Fortress 要塞 | 蓝灰石/金属墙、厚重门洞、少量暖灯 | 门洞与墙体边界明确，避免满屏砖纹 |
| UndergroundFortress 地下要塞 | 深蓝灰石墙，暖黄灯源和少量苔色 | 暗场中玩家、敌弹、通道出口仍可读 |
| MineShaft 矿井 | 暖赭石岩壁、木梁支撑、矿车和灯 | 岩层大块面，支撑架不遮盖通路 |
| Metropolis 城市 | 灰蓝道路、人行道、店面和少量路灯 | 道路边界清楚，路障/出口状态一眼可辨 |

出口继续遵循现有关卡交互：森林/沙滩类用路牌与小径，乡村/城市用道路，要塞/地下环境用门；只改变外观，不新增或暗示玩法规则。

### 道具、武器和可交互物

- 手枪、冲锋枪、霰弹枪、狙击枪、机枪以剪影、枪管长度、弹匣/枪身形状区别；图标统一朝向、描边和阴影。
- 手雷、燃烧瓶、医疗包、弹药箱、货币、研究点、护盾和支援道具沿用当前玩法图标含义，不能只靠颜色区分。
- 木箱、武器箱、商店和门的开闭/可购买状态需在灰度下也可见；交互高亮使用外描边或明亮小角标，不用整件强发光。

### 子弹、爆炸与提示

- 玩家弹：小型尖头暖金弹，枪口焰短促、白黄芯橙色边。
- 敌弹：较大的粉红/珊瑚圆弹，浅色核心；与玩家弹在轮廓和颜色上同时不同。
- 爆炸：白黄中心、橙红外圈、少量深色碎屑；生命周期分阶段，不保留大面积遮挡。
- 近战/落点预警继续对齐真实攻击范围。圆形、直线、扇形分别使用不同形状，不额外增加虚构效果。
- 治疗、拾取、受击、清房反馈用少量十字、星点、环形或闪光；持续时间和亮度不覆盖人物边缘。

### HUD、菜单和文字

- 战斗 HUD 参考截图位置：左上生命、弹药/投掷物；右上小地图；右侧竖排武器槽，选中项用浅色描边。资源数字优先于装饰。
- 血量保留当前数值规则，可用分段心形/心形加数字表达；不因参考图改动生命值逻辑。Boss 血条只在 Boss 战显示。
- 面板用深炭绿、帆布/木质浅底、圆角手绘轮廓。避免目前铜色厚边框、密集螺栓和军事仪表盘式堆叠。
- 主菜单、暂停、商店、升级/结算共用一套按钮与卡片：常态深绿，聚焦浅边高亮，禁用降饱和；卡片图标大、文字短、留白充足。
- 游戏文字保留 Godot 控件可读性与本地化能力；视觉上转为非像素、粗而清楚的中文字体。不要把标题/数值烘焙进可复用 UI 纹理。

## 可复用图像提示词

### 总提示词

> 2D 俯视偏斜视角的手绘卡通军事动作游戏资源。严格参照项目内已确认的森林交火截图与玩家图集：小尺寸、短身人物、简洁大色块、略有变化的近黑轮廓、两到三档哑光明暗、少量自然笔触纹理。玩家低饱和灰橄榄绿/浅米白/棕色；敌人蓝灰并用少量珊瑚红区分；森林地面黄绿、边缘深绿；友弹白芯金黄尖头，敌弹粉红圆形。保持游戏镜头和实际显示尺寸的识别度，不做摄影写实、亮面 3D、密集像素纹理、过细迷彩、霓虹光效和无关装饰。具体主体：{主体}；游戏用途和实际尺寸：{用途/尺寸}；必需剪影特征：{特征}；方向/动作：{状态}；导出：{透明底独立资源/分格图集/场景设计板}。枪口与瞄准方向严格一致，背景透明区域干净，不裁切主体，不加文字和水印。

### UI 提示词

> 以已确认截图中的 HUD 为位置和层级基准，设计深炭绿、暖灰白、橄榄绿和少量金黄组成的卡通游戏 HUD。图标手绘轮廓，数字高对比，面板圆角、薄描边、少量帆布/木质纹理。保留生命、弹药、投掷物、小地图、武器槽的清晰优先级；选中/禁用状态依靠描边和亮度区分。所有文字留给引擎控件，不生成长句；避免铜色厚框、密集螺钉、科幻玻璃、文字烘焙和不必要的信息。

### 环境和物件提示词

> 固定俯视偏斜镜头，使用与确认玩家图集一致的近黑手绘描边、低频块面和轻柔地面阴影。房间中心保持低细节战斗空间，边缘布置{主题对应树木/建筑/岩壁/店面}。只绘制{地面/墙/箱子/掩体/出口}，可行走与阻挡区域边界明确，物件顶面和碰撞占地可读；纹理稀疏，不用重复像素砖或照片素材。出口外观遵循既有主题设计和交互状态。

### 道具和特效提示词

> 以已确认玩家和战斗截图为尺寸、线条、颜色基准，为{既有道具或效果}绘制清晰的小尺寸图形。保留项目规则规定的轮廓和颜色编码；透明背景，单体居中，近黑外轮廓，少量哑光高光；不得加场景、地面、文字、额外道具、强外发光或遮挡主体的大烟雾。运动/攻击方向与玩法参数一致。
