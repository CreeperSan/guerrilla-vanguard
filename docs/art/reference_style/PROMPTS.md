# 本轮图像生成提示词集

生成方式：内置 `image_gen`。用户提供的八格截图仅作为画风与质量参考；本目录的场景和资产为重新生成的设计图，没有直接裁剪截图。角色重装兵另经过一次定点改色。

## 共同要求

> 2D 俯视偏斜弹幕射击游戏。参照用户截图上排第二格明亮手绘卡通的视觉语言：约 1:2 的小人物、清楚的深色描边、每个物体两至三档明暗、适度笔触纹理、鲜明但节制的配色。接近游戏成品素材的质感，保持缩小后可识别；避免写实军事细节、厚重概念画渲染、过密纹理、水印和无关文字。
