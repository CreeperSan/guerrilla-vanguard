# 美术基准 v0.4 · 参考图手绘卡通

状态：以用户 2026-10-09 提供的森林交火截图为当前画面基准；此前的八格设计图仍可作为题材参考。

## 风格

- 采用参考图中明亮的手绘卡通方向：俯视偏斜的 2D 画面，小比例角色、干净的深色轮廓、两至三档主体明暗和少量笔触纹理。完成度接近游戏内素材，不追求军事装备或建筑的写实细节。
- 玩家使用截图中的短身形和较大的灰橄榄色头盔，浅色脸与袖口、深色短腿、棕色小背包、近黑色步枪；不要添加截图里没有的 V 标记或围巾。敌方步兵与突击兵身形相近，重装兵明显更宽；首领为固定的通信装甲装置。
- 玩家以低饱和橄榄绿和棕色识别；所有敌方普通单位使用深蓝灰与珊瑚红。重装兵不得再使用接近玩家的绿色主色。
- 友方子弹是金黄尖头，敌弹是更大的珊瑚红圆点；预警线、扇面与实际攻击方向一致。即使去色，也能凭形状区分。
- 本轮设计图保留参考图的鲜明层次，但环境中心尽量留出低细节战斗区域，繁复植被、箱子、招牌与墙面装饰集中在房间边缘。之后组装实机画面时必须重新检查遮挡与对比。

## 玩家资产基准

当前采用用户确认的 2026-10-09 参考图玩家方向稿。原画为 `Assets/Art/MilitaryArcade/source/player_reference_24_refined.png`，运行图集为 `player_reference_atlas.png`；`tools/package_reference_player.py` 可重复打包。每帧 96×80，八行依次为下、右、上、左、右上、左上、左下、右下，每行是待机和两帧交替迈腿。枪口必须严格指向该行瞄准方向，不能因为身体视角变化而改为水平持枪。运行节点采用线性纹理采样，角色尺寸沿用现有场景缩放。图集接入后仍需在真实场景里检查相对环境尺寸、动作连续性与遮挡。

## 六类环境与出口

| 场景 | 视觉重点 | 出口形态 |
| --- | --- | --- |
| 森林 | 浓绿树冠、浅草和土路 | 木路牌 + 林间小径 |
| 沙滩 | 金色沙地、青蓝海水与海岸岩石 | 木路牌 + 沙路 |
| 乡村 | 暖土、篱笆、补给棚与谷仓 | 乡间道路 |
| 要塞 | 蓝灰金属板、通信设备与门框 | 金属门洞 |
| 地牢 | 浅紫石砖与短墙 | 石质门洞 |
| 城市 | 灰蓝马路、人行道与低矮店面 | 连续马路 |

当前普通三关建议沿用**森林外围哨站 → 乡村补给营地 → 通信要塞**。沙滩、地牢、城市为可扩展环境设计；并不意味着 v1.0 策划已经增加关卡。六类场景统一使用相同的玩家、敌人、弹幕与 UI 绘制语言。

门、路牌和马路是相同关卡交互的不同外观：都要提供目的地、`E` 提示和确认，未满足通行条件时有可见的实体阻断。门板合上/打开、路牌灰显并有路障/高亮且小径可见、马路路障拦截/移开。第 3 关出口仍按策划执行撤离结算，首领胜利直接结算。
