# 《Guerrilla Vanguard》美术设计

当前阶段：**玩家、敌人/将军/坦克、七主题全套地形图、十二种武器/补给图标、常用投射物/爆炸/燃烧、HUD 面板、主菜单背景和字标已接入参考图风格**。界面字体和少数关卡专属物件仍待迁移或复核。本轮整体规范与资源预览见 [2026-10-09 美术重设计](rework_2026-10-09/STYLE_SYSTEM.md)。

当前游戏风格以用户提供的森林交火截图和已确认玩家图集为准：低饱和小比例角色、深色手绘轮廓、哑光色块、稀疏纹理、清晰弹幕和开阔战斗区。早期设计稿可作历史资料，若与新基准冲突则以新基准为准。
