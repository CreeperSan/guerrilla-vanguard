# 游戏首页

项目主场景为 `Scene/MainMenu/MainMenu.tscn`。首页使用新生成的封面和透明图片标题，保留旧 `title.png` 文件。各页面的按钮、滑块、标题和升级槽位均为场景中的可编辑节点。

## 菜单与导航

1. 开始空降：加载持久战斗宿主，直接按空降模式开始 5 关闯关及 3、2、1 倒计时。
2. 开始强攻：默认禁用。完整通关一次正式空降模式并成功结算后开放；强攻对应原总攻模式，6 个随机战场加固定地下要塞终点。
3. 战场升级：进入独立全屏页面，切换研究基地背景，显示已存研究账户与六个禁用升级槽位。未实现具体升级，不扣研究点数。
4. 游戏设置：音乐和音效分别调整音量、快捷静音；删除存档需要二次确认。
5. 关于游戏：显示游戏名称、玩法与两种闯关模式说明。
6. 退出游戏：保存最后一次音频设置，正常调用引擎退出。

子页面可以点击返回首页或按 Escape / 手柄返回键。结果页增加返回首页入口，重新开始也回到首页重新选择模式。原有退出游戏行为保留。

## 持久化与删除

`user://research_account.cfg` 升级为版本 2，保留已有版本 1 的研究余额，新增 `progress/airborne_completed`。只有正式空降最后一关安全出口确认胜利才传入通关标志；Boss 死亡、单关 F6 测试、战败均不解锁。

研究与通关标志同时保存，存盘失败时暂不解锁；在结果页重试成功后生效。首页和 GameManager 启动入口均检查解锁。

删除弹窗明确说明清空研究余额与强攻解锁，默认聚焦取消。确认后只删除账户文件及其临时文件，清空内存账户和对局数据；不递归删除整个用户数据目录，不删除音量设置。删除错误时显示错误码。

## 音频

AutoLoad `GameSettings` 创建独立 Music / SFX 总线，既有默认 Master 音效播放器自动路由到 SFX。首页与七种 Level 采用不同的原创电子像素风配乐，均为 16 小节完整乐句循环，见 [配乐清单](../Assets/Audio/Music/README.md)。

配乐由 `tools/build_background_music.py` 作曲与加法合成生成，依赖 numpy，没有引用外部音乐或采样。音符尾音和延迟环绕写入，首尾呼应；运行时直接设置音频资源循环，避免 finished 回调重新播放引入空隙。进入 Level 或返回首页时交叉淡化 0.8 秒，同一 Level 切房间不重播。各主题 `theme.tres` 的 `background_music` 可在 Inspector 替换。

音乐 / 音效的音量和显式静音分别存到 `user://audio_settings.cfg`。快捷静音不覆盖原音量，恢复时沿用原数值。拖动滑块即时生效，保存合并到 0.25 秒一次；退出前主动保存。战斗暂停菜单的音效滑块同步同一个 SFX 设置，避免调整音效时连音乐一起变小。

## 美术

三张图片由内置 image_gen 生成，已经复制到 `Scene/MainMenu/Art/`，不依赖 Codex 生成目录。封面和升级背景按画面铺满并裁切，标题保留真实透明度。生成提示词记录见该目录的 `README.md`。

## 手动检查

- F5 应首先进入首页，出现图片标题和全部六个菜单；新存档的强攻禁用并显示原因。
- 点击空降应直接进入倒计时，不再重复选择模式；按住或连按按钮不应创建多个战斗宿主。
- 完成空降五关并从最后一个 Boss 安全出口结束后返回首页，强攻开放。重启游戏后解锁仍在；仅击败一个 Boss 或战败不能解锁。
- 战场升级显示已存研究余额和六个占位，不产生扣款；返回首页保留账户。
- 两类音量和静音独立变化、重启后保留；战斗内调音效不影响背景音乐。
- 首页、不同主题 Level 切换为不同音乐，同一 Level 房间切换不中断；听完整一轮确认衔接自然。返回首页恢复首页曲，换曲短暂交叉淡化。
- 删除先取消，余额和解锁保持；再次打开并确认，研究归零且强攻锁定；重启后仍锁定。
- 用键鼠、手柄和触控检查按钮、滑块、返回键和确认框；检查常见横屏比例下封面铺满、菜单可见。

本轮未运行自动测试，未验证 Godot 实机渲染、音频混音与磁盘存档。已检查资源与场景节点引用，并人工查看三张生成美术资源。
