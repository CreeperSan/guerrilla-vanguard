# 战斗补给房

每关地图额外生成且仅生成一间 1×1 战斗补给房。它是非主线的单入口支路，连接普通战斗房，不连接 Boss；普通随机布局和兜底布局都遵守这一规则。房间在首次进入时生成 7 名敌人，暂不放置普通木箱、地面随机补给或水域。

敌人全部清除后，房间自动打开锁闭的补给箱并生成五份拾取物：一件随机武器、一件随机装备、医疗包、金钱和研究点数。奖励由房间种子稳定抽取，遵循现有 `LootItem`、`CurrencyPickup` 和本局货币入账逻辑。离开后再次进入时，打开状态与剩余奖励保留。

补给箱的闭合/开启图集位于 `Assets/Art/MilitaryArcade/World/battle_supply_cache.png`。Sprite2D 使用横向两帧图集，左侧关闭，右侧开启。小地图用“补”字和暖金色标识该房间。

契约测试：`tests/battle_supply_room_test.tscn`，覆盖多关多种子及兜底地图的唯一性、可达性、单入口、无重叠，并验证清场前锁定、清场后打开和五类奖励。
