# 手机触控与用户设置

设置页为单个纵向滚动列表，保留四个分组标题，返回首页按钮固定在底部。设置入口：**首页 → 设置 → 向下滑动到操控分组**。

- **显示**：重温游戏剧情。进入开场剧情场景立即保存 `story_intro_seen = true`，以后启动经过工作室开场直接进入首页。新配置默认为 false；旧版跳过开关不参与判断。
- **操控**：固定 / 活动十字移动、移动区大小（50%～150%）、布局编辑、布局重置。
- **音效**：背景音乐与音效音量、各自静音。
- **其他**：删除游戏存档，沿用二次确认。删除研究账户不会删除用户设置。

## 布局编辑

独立场景：`Scene/TouchLayout/TouchLayoutEditor.tscn`。点击 / 触摸按钮标记后拖动；底部下拉框也能选择被其他按钮遮挡的标记。顶部“面板”按钮可折叠底栏，完整查看和拖动靠近底边的按钮。X、Y 滑块按屏幕百分比微调中心，大小滑块为默认大小的 50%～160%。

可编辑十字移动、十字瞄准、射击、换弹、装备、战场支援、奔跑 / 闪避、小地图、武器切换、战术装备。两只摇杆的完整保存区域分别限制在左 / 右半屏。其他按钮可以自由摆放，允许重叠以支持自定义布局。

编辑期间仅修改草稿；**保存**一次提交并立即落盘。**取消**或返回键在有修改时确认放弃。编辑器的重置仅恢复草稿；设置页的重置立即恢复按钮布局，保留移动方式与移动区整体倍率。

移动区显示及固定模式触摸命中均为圆形，外接矩形四角不会触发移动；编辑器同步使用圆形标记。活动移动以左半屏第一根手指落点为中心，第二根手指不会抢占；靠近边缘时图形裁剪在左半屏，输入原点仍精确对应手指。手指释放、窗口失焦、切换输入设备或调整设置时清理虚拟输入。瞄准区沿用按住射击、拖动转向的交互，另提供独立射击按钮；同时按住两者时需全部释放才停止开火。

## 修改默认布局

唯一默认表为 `Script/Global/touch_layout.gd` 中的 `DEFAULTS`：

- `center`：归一化中心，`Vector2(0.2, 0.7)` 即宽度 20%、高度 70%。
- `size`：1280×720 参考屏幕的逻辑边长；按实际视口等比适配。
- `scale`：默认倍率。
- `EDGE_MARGIN`：默认边缘留白 48 参考像素。
- `BUTTON_OPACITY` / `MOVEMENT_OPACITY` / `MAP_OPACITY`：普通触控按钮不透明度 55%，左侧移动摇杆 22%，小地图 45%；切回键鼠/手柄时还原原始透明度。

移动区由 154×154 增至 308×308（边长 +100%）；原右侧按钮边长 +30%。保存中心与倍率，基准尺寸仍由默认表维护。武器面板恢复右上角，小地图缩至 176×112 参考像素并放在武器面板下方，换弹按钮下移留出间隔。本次版本升级会自动迁移旧版未修改的默认位置，保留手动自定义位置；以后修改默认中心，已有用户可通过重置采用新位置。

设置保存在 `user://audio_settings.cfg` 的 `presentation`、`controls`、`audio` 分组，与研究存档分开。布局加载会补齐新增按钮、过滤错误类型并限制非法倍率。

桌面自动验证不能替代手机真机对握持舒适度、刘海安全区和长时间触控手感的验收。

本次验证：触控回归 196/0、战斗库存界面 20/0、真实启动与重温导航 18/0、剧情/战报流程 40/0；桌面图形模式渲染检查通过。既有 `player_actions_and_hints_test` 在第 110 行引用早已不存在的 `_stamina_fill_style` 字段而中断；此次未修改该测试及无关玩家逻辑。

结算页正文支持单指上下拖动和松手减速滚动；手势只从正文区域开始，底部按钮保持固定。滚动到边缘会夹紧，系统取消手势或窗口失焦后清理触点与惯性。自动验证通过视口输入分发覆盖标签区域滑动、多指不抢占、边界夹紧及取消释放。
