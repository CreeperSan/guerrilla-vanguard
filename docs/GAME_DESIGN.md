# Guerrilla Vanguard 游戏策划

版本：2026-09-29 实施基线。阅读入口见 [README](README.md)，全部具体参数见 [数值表](BALANCE.md)。

## 1. 游戏要做成什么

一款单人、离线、2D 俯视角 RogueLike 射击小游戏。玩家不断突袭要塞外围，收集情报，回指挥部获得永久强化，最终空降敌方指挥部击败首领。严格说含永久成长的结构更接近 Roguelite；项目不为术语增加额外系统。

默认目标平台是开发者当前使用的 macOS 桌面，键盘操作；其他桌面导出在本机完整验收后处理。首版不做触屏、手柄和多平台同步开发。沿用现有 Godot 项目和素材风格，不升级引擎作为开发前置任务。

完成标准是：第一次打开游戏能学会操作，能失败并带回情报，能升级再挑战，能通关普通三关，能进入独立最终任务并看到结局，退出重启后永久进度正确保留。

## 2. 故事与表现边界

虚构地区“岚谷”遭“铁幕军团”占领。敌方指挥官利用要塞通信网持续调动部队，封锁外界援助。玩家是游击队“前哨”派出的空降兵，负责收集外围据点的通信记录、补给路线和指挥部坐标。

三关普通行动依次是外围哨站、补给营地、通信要塞。它们共用图块和房间模板，通过关卡名、少量配色与敌人组合区分，不要求三套美术。首次完成通信要塞后掌握敌方指挥部位置；每次完成普通行动都会准备好一次最终空降所需的实时行动窗口。

情报用于改善作战指挥部的医疗、武器校准和补给能力。战斗中获取的数据实时上传，因此阵亡仍保留已获取情报。失败后由同编制后续士兵继续行动，保持相同外观和操作，不做角色继承系统。

最终首领称为“要塞指挥官”。击败后通信网络被切断，敌军失去统一指挥，岚谷封锁解除。故事不扩展到战争政治模拟。

只做四处短文本：首次进入指挥部的任务简报、首次解锁最终任务、最终任务开场、胜利结局。空降用黑屏文字和淡入表示；不制作飞机、降落伞、过场动画、配音、对话树或剧情选择。

建议直接使用的文本：

- 开场：“你已抵达岚谷外围。夺取敌方数据，改善指挥部支援能力，并找到最终空降的行动窗口。”
- 解锁：“通信要塞数据已上传。敌方指挥部坐标确认，最终行动已解锁。你可以立即出击，也可以继续准备。”
- 最终开场：“空降完成。击败要塞指挥官，切断敌方指挥链。”
- 结局：“指挥网络已瘫痪，岚谷封锁解除。此次行动结束。”

## 3. 首版边界与后续扩展

| 系统 | v1.0 必须交付 | v1.1 既定扩展 |
| --- | --- | --- |
| 普通行动 | 3 关，共 24 房，包含 12 个战斗房 | 复用 |
| 最终行动 | 独立的 1 个首领房 | 5 关共 40 房，含 20 个普通战斗房和 1 个首领房 |
| 房间 | 入口、商店、武器库、出口、战斗、首领；九种宽高规格 | 添加少量模板，不增加房间类型 |
| 随机性 | 布局模板抽取、房间模板分配、敌群、武器库和商店货品 | 同一套规则用于五关最终任务 |
| 枪械 | 手枪、冲锋枪、霰弹枪、狙击步枪、重机枪 | 不增枪种 |
| 消耗品 | 手雷、即时医疗包 | 燃烧瓶、盾牌 |
| 支援 | 暂不做 | 导弹打击、重机枪空投 |
| 敌人 | 步兵、突击兵、重装兵、双阶段首领 | 最终路线使用更强敌群配置 |
| 局外成长 | 生命、手枪伤害、初始物资，四种额外出击武器解锁 | 不增加技能树 |

九种房间尺寸不代表九套美术：共用图块与四个门口组件，制作九个不同尺寸的战斗模板即可。地图不要求无缝移动；逐房间切换，使用经过验证的逻辑布局，细节见 [关卡约定](LEVEL_AND_SYSTEMS.md)。

不做：联机、队友 AI、潜行感知、载具、制作、装备词条、随机天赋、复杂寻路地图、破坏地形、任务分支、多结局、成就、排行榜、每日挑战、云存档、局内断点续玩。已有枚举中出现的喷火器、火箭筒、防弹衣也不属于本路线。

## 4. 完整流程与最终任务资格

主菜单 → 指挥部 → 普通行动或最终行动 → 结算 → 指挥部。首次无进度时，最终按钮显示解锁条件。

**普通行动**：选择额外出击武器，带手枪和满生命出发；连续打第 1、2、3 关。跨关保持生命、枪械、弹药、消耗品、物资和本轮情报，不回指挥部、不进行永久升级。完成第 3 关出口后结算，本轮装备与物资清零，情报全额入账。

**两种状态必须分开：**

- `final_unlocked`：首次普通三关通关后永久为真，不会因死亡消失。
- `final_ticket`：一次最终任务出击资格，只有 0/1，不可囤积。每次普通三关通关设为 1，开始最终任务时立即消耗并保存。

玩家拿到资格后可在指挥部升级、退出游戏或继续普通行动。继续普通行动失败不会扣掉已有资格；再次通关也不会叠加。开始最终任务视为新一轮，重新带满生命、初始物资、手枪及所选已解锁额外武器，不继承上一轮背包。最终任务阵亡或主动放弃后资格为 0，必须重新通关普通三关；永久解锁仍保留。

最终胜利后展示结局、结算并记录已通关。玩家可回指挥部继续玩；下次最终任务仍需一次资格，不做二周目增难。

**结算优先级**：玩家死亡优先于本帧出口触发或首领死亡；同归于尽按失败结算。死亡或胜利只允许进入一次结算。主动退出行动也结算已获得情报，不发通关奖励。

**异常退出**：首版不恢复局内进度。每次情报实际到账时保存“待结算情报”；重启后将其全额转入永久余额，按中断行动返回指挥部，不发通关奖励。物资、装备与局内地图丢弃；已经消耗的最终资格不恢复。开局和退出界面明确告知不支持局内续玩。

## 5. 操作与战斗

| 操作 | 按键 | 规则 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 八方向，斜向归一化；移动改变朝向 |
| 射击 | 按住 J | 朝当前面向连续射击；停止移动保留朝向 |
| 换弹 | R | 手动换弹；可移动，不可射击 |
| 换枪 | 1 / 2 / 3 | 手枪 / 第一额外槽 / 第二额外槽；空槽忽略 |
| 交互 | E | 拿武器、补给、购物、使用出口；最近可交互对象显示提示 |
| 使用手雷 | K | 沿当前面向投掷，无鼠标瞄准 |
| 暂停 | Esc | 暂停战斗、计时与投射物；菜单可继续或放弃 |
| 地图 | Tab 按住 | 显示本关完整简图，无战争迷雾 |

不增加翻滚、冲刺、锁定朝向或鼠标瞄准。移动朝向射击意味着玩家需要转身再攻击；首轮测试先用宽敞房间和慢弹速验证可用性。

三枪槽：手枪固定且不可丢弃；其他枪型每种最多一把。非手枪空槽按 2 再 3 的顺序填入；满槽时拾取不同枪替换当前选中的额外槽。若此时选中手枪，提示“先按 2 或 3 选择替换武器”，不自动替换。旧枪直接销毁，不落地、不卖回；拾取前提示替换后旧枪及其弹药会丢失。拾取已有枪型仅补充该枪备弹，按数值表执行。满弹不消耗拾取物或金钱。

切枪取消换弹；换弹完成时才扣备弹并补弹匣，不允许通过切枪免费装弹；射击冷却跟随各武器，切枪不能刷新。弹匣空时点击只提示 R，不自动换弹。**手枪有有限常规备弹，但零备弹时允许同样耗时的紧急换弹补满弹匣**，不产生备弹；这是避免无弹死局的明确保底。其他武器无此功能。

普通子弹不穿透、不反弹、不追踪，命中有效敌人或墙体后消失。友方不互伤，敌方不互伤；接触敌人本体不自动扣血，只有攻击判定造成伤害。玩家受伤后短暂无敌并闪烁，避免重叠子弹瞬间清空生命。没有暴击、爆头、防御公式或硬直链。

每次入战斗房封门，敌人一次性全部生成，预警结束后开战；清敌后清除残余敌弹、发放一次清房奖励并开门。没有多波刷新。玩家入门落点与敌人出生点保持安全距离。走进已清理房间不刷敌、不重复发奖。

## 6. 房间与资源交互

| 房间 | 行为 |
| --- | --- |
| 入口 | 无敌人，提示本关目标；不提供恢复 |
| 战斗 | 3–5 敌人，封门清敌；掉物资，清房发情报和补给 |
| 商店 | 安全房，本关固定库存；按 E 打开暂停面板，购买后标记售罄 |
| 武器库 | 安全房；免费武器箱、弹药箱、医疗包和手雷包各一次 |
| 出口 | 安全房，按 E 确认进入下一关；第 3 关出口改为撤离结算 |
| 首领 | 封门战斗；胜利时结算。v1.0 最终任务直接进入此房，开战前显示操作提示 |

每个普通关卡包含入口、商店、武器库、出口各一间，其余全为战斗房，即 2/4/6 间。支线可跳过；出口路径必须经过规定数量的战斗房，不能完全绕过战斗，具体约束见关卡文档。

物资由击杀掉落，接触自动收取；清房时自动收取本房剩余物资，避免找零钱。情报在清房时直接上传，无需捡数据模型。子弹和货币不会跨房间残留。战斗房中的可选医疗包等补给保留到离开本关，返回可拿；离开本关之后不可返回。

武器、医疗包、弹药、手雷按 E 领取；满生命/满库存时不消耗物品。商店与武器库界面展示实际效果。开商店、武器库面板和确认对话时暂停；关面板恢复。交互重叠按距离再稳定对象 ID 排序，一次按键只触发一个对象。

物资仅本轮有效；情报只有结算后可用于永久购买。指挥部是菜单，不做能走动的基地场景。每次出击满生命，额外武器带其初始弹匣与备弹；初始手雷为 0。

## 7. 敌人与首领行为

- **步兵**：开战锁定玩家；距离远时靠近，进入射击距离后停下，前摇提示，向发射瞬间的玩家位置打一发慢速直线弹。前摇期间不移动。没有视野锥、巡逻、追踪弹和预判。
- **突击兵**：直线追击；接近后停下蓄力，前摇结束检查距离。玩家离开攻击范围即打空，不瞬移追击；冷却时继续移动，不靠持续接触造成伤害。
- **重装兵**：复用步兵状态，只改变生命、移速和射击参数，使用明显不同的颜色或体型。
- **首领**：固定在宽敞首领房中心，不寻路、不召唤。上半血重复单发攻击；生命低于 50% 后进入二阶段，单发更快，并按“单发、单发、三发扇形”循环。每次发射前都有提示，扇形不与单发同一时刻叠加。换阶段只切换参数和循环，不清弹、不回血、不插入无敌演出。

房间内不放会挡住敌人追击的实体内墙，装饰无碰撞，只有外围墙和门有碰撞；首版因此无需复杂寻路。敌人之间不做刚体推挤，允许轻微重叠；仍与外墙碰撞。门封闭期间玩家留在房间内，不存在跨房追击。

## 8. 道具与扩展支援

v1.0 医疗包立即恢复生命，不入背包；手雷为独立计数，沿面向到固定距离后延迟爆炸，只伤敌，不伤自己，无抛物线物理模拟、击退和地形破坏。遇墙则停在墙前爆炸。爆炸半径内每个敌人只受伤一次。

v1.1 增加以下内容，首版只保留配置分类与槽位概念，不做空按钮：

- 燃烧瓶：与手雷共用投掷轨迹，落地生成短时圆形持续伤害区域；不蔓延，同一敌人受到多个火区影响时只取一份火焰伤害。
- 盾牌：消耗一件后获得短时完全免伤，不反射，不叠持续时间；生效期间禁止再次使用。
- 导弹：沿面向选点，显示圆形标记，延迟一次范围伤害，无摄像机切换和飞行器模型。
- 重机枪空投：在玩家附近安全点生成重机枪拾取物；仍遵守枪槽与重复武器规则，不自动装备、不额外创造第四槽。

v1.1 用 Q 在持有的手雷/燃烧瓶/盾牌之间循环、K 使用当前道具；F 在两个支援间循环、G 使用。数量为 0 的项跳过，无可用项则提示。支援不可在安全房使用，空投在战斗房也可使用，失败生成不扣次数。所有具体上限和参数见数值文档。

## 9. 局外成长与界面

指挥部显示永久情报、三项强化及当前等级、四种初始武器解锁、额外出击武器选择、普通行动、最终行动、返回菜单。额外出击武器只选一把，另一槽留空；手枪始终携带。购买前显示成本和升级前后差值，余额不足或满级禁用。购买即保存。没有装备管理、卖出、洗点或角色等级。

HUD：生命/最大生命、当前枪和弹匣/备弹、三个枪槽、本轮物资、本轮情报、手雷数、关卡名称。手枪紧急换弹提示明确；满级强化不再显示购买按钮。首版提供总音量开关或滑条，设置按钮必须可用。

结算面板：胜利/阵亡/撤离/中断原因、到达关卡、击杀数、本轮情报、普通通关额外奖励、获得或消耗的最终资格；物资不兑换情报。结局文本显示后回到同一结算流程。

存档与异常路径见 [系统约定](LEVEL_AND_SYSTEMS.md)。完成验收和下一步任务见 [开发清单](DEVELOPMENT_PLAN.md)。
