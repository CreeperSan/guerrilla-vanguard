## 原生像素素材

| 目录 | 数量 | 尺寸与用途 |
| --- | ---: | --- |
| `sprites/characters/` | 13 | 玩家 8 方向 32×32；三敌 32/36×32；首领两阶段 64×64 |
| `sprites/weapons/` | 5 | 五枪 64×32，枪口统一朝右 |
| `sprites/items/` | 9 | 首版医疗包、手雷、弹药、情报、物资和 v1.1 四项扩展；32×32 |
| `sprites/props/` | 14 | 六种出口各有封锁/开放状态，另有商店和武器箱；64×64 |
| `sprites/environments/` | 6 | 六种 160×112 的色彩与组合样张；用于审阅，不作实际房间贴图 |
| `sprites/effects/` | 12 | 双方弹丸、两种预警、爆炸三帧、治疗、上传、受击亮边、枪口、清房 |

角色与敌弹保持跨环境固定配色。森林/乡村/要塞是当前三关建议；沙滩/城市/地牢已经有独立环境设计，但是否进入实际关卡由后续关卡策划确定。门、路牌和道路只改变出口外观，游戏内仍使用一致的 `E` 交互、目的地提示和确认逻辑。

设计图用 `build_designs.py` 生成：`python3 docs/art/design/build_designs.py`。源文件保留具体像素位置、颜色、状态和排版，图纸上的数值只作 UI 排版样例，玩法参数仍以 `docs/BALANCE.md` 为准。

接下来的完整实机效果应从这些设计图选用资产，在实际战斗尺寸下组装普通战斗房和首领房，检查 3–5 名敌人、弹幕、预警、交互提示及 HUD 的重叠与辨识度。本目录不包含该阶段的渲染图。
