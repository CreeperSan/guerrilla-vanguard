# 世界美术接入

本目录保存上一轮生成的敌人、首领、七类地形与战斗效果。源图在 `source/`，生成记录在 `generation_manifest.json`；旧游戏素材保留。

## 绑定与显示

- 敌人：`enemy_atlas.png`，3列×8行，96×80/格；列为站立、行走A、行走B，行依次为下、右、上、左、右上、左上、左下、右下。正式 EnemySoilder 预制体沿用原动画名和制服染色，显示缩放0.4。
- 首领：`boss_atlas.png`，2列×8行，96×96/格；列为第一阶段手枪、第二阶段冲锋枪，方向行与敌人相同。正式 BossGeneral 按玩家位置选择45度方向分区，停下和换弹时也持续转向，目标重合时保留上一朝向。显示缩放0.4，碰撞体不旋转。
- 首领原图部分枪口方向有误：第一阶段右上复用左上镜像；第二阶段左、左上、左下分别复用对应右向格镜像。阶段切换立即更新武器列，原有第二阶段染色保留。
- 爆炸、燃烧：各四帧64×64；爆炸播放一次，燃烧循环。缩放分别0.5、0.75，伤害半径、伤害值和持续时间沿用现有逻辑。TestLevel 改为引用正式效果预制体。
- 飞行物：手雷、燃烧瓶、下落炮弹采用独立飞行图；敌方普通子弹使用红色曳光弹并随飞行方向旋转。替换图片时取消旧图集裁切。
- 七类关卡：各主题资源绑定独立地面、墙、水、箱子、掩体与装饰，出口统一使用 `entrance.png`。测试房间使用16像素地砖专用图。像素美术使用最近邻采样，房间布局、掩体数量和碰撞尺寸保持原配置。
- `crate.png`、`sandbags.png`、`crater.png` 作为通用备选素材保留；当前地图使用主题专属箱子与掩体，没有新增弹坑机制。
