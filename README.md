# Guerrilla Vanguard

一个使用 Godot 制作的 2D 俯视角动作射击原型。项目目前处于开发阶段，包含基础场景切换、玩家移动与射击，以及用于验证敌人和战斗组件的测试场景。

## 当前功能

- 启动后显示约 2 秒的 Splash 页面，然后进入主菜单。
- 主菜单可以开始游戏或退出；设置按钮目前尚未实现。
- 玩家支持八方向移动和对应动画，并可朝当前面向发射子弹。
- `TestLevel` 中包含敌人、生命组件和感知区域的原型。

## 环境与运行

- **引擎：** Godot 4.7
- **渲染：** GL Compatibility

使用 Godot 编辑器打开仓库根目录下的 `project.godot`，等待资源导入完成后运行项目（Run Project）。也可以在已安装 Godot 命令行程序的环境中运行：

```sh
godot --path .
```

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 射击 | `J`（朝当前面向发射） |

## 项目结构

```text
.
├── Prefab/Item/              # 子弹场景
├── Scene/
│   ├── Splash/               # 启动画面
│   ├── MainMenu/             # 主菜单
│   ├── Level_01/             # 当前开始游戏进入的关卡
│   └── TestLevel/             # 玩家、敌人和战斗组件测试场景
├── Script/
│   ├── Component/            # 生命值等通用组件
│   ├── Enemy/                # 敌人控制与感知原型
│   ├── Items/                # 子弹逻辑
│   └── Player/               # 玩家控制
├── Tileset/                  # 测试图块与角色素材
└── project.godot             # Godot 项目配置、输入映射和主场景
```
